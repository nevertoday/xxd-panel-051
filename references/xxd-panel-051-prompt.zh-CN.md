# XXD Panel 051｜空气蓝横向微缩纸艺景观生产提示词

只处理当前新任务明确提供的这一张源照片。私下锁定主体身份、轮廓、比例、姿态、方向、动作、结构、关系、环境气质、生活细节与源图综合色温；至少保留三个源图专属线索，不得借用其他输入、旧输出或样张。

## 审美重构

把源图重构成一件精致的 miniature 3D paper-craft 微缩纸艺装置。核心结构是一个一眼可辨的手工微缩主体、一条狭长轻盈的横向悬浮景观带、少量真正强化身份与环境气质的陪衬模型，以及大面积干净浅色纸面。不要机械复刻照片，也不要建造一个塞满物件的完整玩具世界。

严格遵循这条因果链：锁定主体、轮廓、姿态与叙事关系 → 保留三个专属线索 → 重构一个可辨识手工微缩主体 → 只提炼必要陪衬模型 → 组织于一条狭长横向悬浮景观带 → 显示纸纤维、折边、切口、层叠厚度与微小误差 → 用柔和微距光和细腻接触阴影建立体积 → 保留大面积浅色纸面 → 让文字像小型作品签名融入。

## 硬性视觉要求

- 主体保持一眼可辨，从身份、剪影、比例、姿态、轴线、动作、结构、功能、距离或关系中保留至少三个源图专属线索。
- 只建立一个核心主体与一条狭长、轻盈、横向延展的悬浮景观基座。根据源图调整高低、前后、疏密与左右重心；整体可居中但不得僵硬对称。
- 只将有源图依据的少量陪衬转化为纸张、卡纸、软陶、薄木片等手工模型。植物、道路、水面、灯具、交通工具、人物、飞鸟或云朵只能强化叙事，不得无意义堆砌。
- 通过尺度变化、层叠遮挡、小型前景和背景建立纵深。主体承担主要视觉重量，陪衬更小、更轻；基座不得厚重，不得成为封闭完整玩具场景。
- 必须看见真实手工证据：纸纤维、折边、切口、层叠厚度、轻微毛边、细小接缝与不破坏精致度的制作误差。使用柔和自然漫射光和细腻接触阴影，形成 macro photography 般的可触摸体积；拒绝光滑塑料感。
- 以浅粉蓝、雾蓝、天空蓝与空气感冷调蓝建立主氛围，以象牙白、奶油白、浅米色、柔和灰绿、鼠尾草绿和建筑中性色平衡；dusty rose 或 muted blush 仅作微小点色。颜色柔和但干净，拒绝灰脏、泛黄与糖果色。
- 背景保持柔和白色或极浅色纸面与大量留白，使作品像被精心拍摄的高级手工旅行明信片。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。原始档案历史上提到英文标题，但生产时必须服从已经确认的目标语言，不把英文设为默认。自动文案从地点、主体身份、主题、情绪、深意或隐藏关系中提炼一个短标题，不限定城市名。

采用目标文字体系中小型、精致、略带手写感的字形，优先位于景观带下方留白，也可轻微弯曲、沿基座排列或与模型形成空间呼应。保持极少、优雅、克制，像作品签名而不是商业标题，不加入大段说明。用户准确文案逐字保留；无文字模式不得出现字母、数字、标签或伪文字。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计和壁纸不显示原照片。每张壁纸按设备重新组织横向景观带与留白，不裁切其他设备成果。连贯套装始终共同参考原照片与同一张批准定调图，绝不串联衍生图。

拒绝：塑料3D、玩具展示、儿童手工感、通用微缩景观、厚重基座、复杂堆积、过度可爱、电商陈列、平面矢量替代、光滑合成材质、无手工证据、灰脏或泛黄配色。也拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语与不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
