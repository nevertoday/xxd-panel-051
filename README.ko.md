> 종이 공예 미니어처 · 가로형 부유 풍경대 · 손작업 증거 · 에어리 블루 · 넓은 여백

원본에서 가장 알아보기 쉬운 주체와 서사 관계를 손으로 만든 종이 미니어처 설치물로 바꿉니다. 식별 가능한 중심 모형 하나, 가볍고 좁은 가로 풍경대 하나, 근거 있는 소수의 보조 모형, 실제 종이 섬유와 넓은 옅은 종이 여백으로 구성합니다.

## 미학적 논리

```text
주체·윤곽·자세·서사 관계 고정 → 고유 단서 3개 보존 → 식별 가능한 손제작 미니어처 재구성 → 필요한 보조 모형만 추출 → 좁은 가로형 부유 풍경대에 배치 → 종이 섬유·접힌 가장자리·절단면·겹 두께·작은 오차 노출 → 부드러운 매크로 빛으로 부피 형성 → 넓은 옅은 종이 면 유지 → 문구를 작품 서명처럼 통합
```

무관한 사진으로 바꿔도 인식성, 모형 구조, 재료 선택, 풍경대 리듬, 색 관계와 문구가 실질적으로 변하지 않는다면 이 Panel의 결과가 아닙니다.

## 시각적 원칙

- 원본 고유 단서를 최소 3개 보존해 중심 손제작 모형이 한눈에 식별되게 합니다.
- 중심 주체 하나와 좁은 가로형 부유 풍경대 하나만 만들고, 보조 모형은 원본 근거를 갖고 더 작고 조용하게 둡니다.
- 크기 변화, 겹침, 작은 전경과 배경으로 깊이를 만들며 딱딱한 대칭과 두꺼운 받침을 피합니다.
- 종이 섬유, 접힌 가장자리, 절단면, 겹 두께, 잔털, 접합부와 작은 제작 오차를 부드러운 확산 매크로 빛 아래 드러냅니다.
- 에어리 블루를 아이보리, 크림, 옅은 베이지, 회녹색, 세이지, 건축 중성색과 균형 있게 사용하며 뮤트 블러시는 작은 점만 허용합니다.
- 플라스틱 CG, 장난감 전시, 유아적 공예, 범용 디오라마, 과밀, 과도한 귀여움, 전자상거래 진열, 평면 벡터 대체, 탁함과 황변을 거부합니다.

전체 규칙은 [SKILL.md](SKILL.md)와 [생성 프롬프트](references/xxd-panel-051-prompt.en.md)를 참조하세요. 원문의 미학을 보존하지만 역사적인 3:4 화면은 숨은 기본값이 아닙니다.

## 조합 가능한 네 가지 출력

`1`, `1+3`, `1,2,4`, `전체`로 하나 또는 여러 모드를 선택할 수 있으며 `전체`는 원본당 독립 PNG 7개를 만듭니다. 모드 선택 뒤, 생성 전에 완성 이미지 전체의 화면비를 반드시 확인합니다: 원래 프롬프트의 `3:4`, 명시적인 원본 비율, 일반 비율, 사용자 지정 비율／정확한 픽셀입니다. 원본 크기를 묵시적으로 적용하지 않습니다.

| 모드 | 화면비 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 사용자가 확인한 전체 캔버스 | 완성 캔버스를 한 번에 생성: 위에 고충실도 원본, 아래에 051 디자인, 약 50/50 |
| `left-right` | 사용자가 확인한 전체 캔버스 | 완성 캔버스를 한 번에 생성: 왼쪽에 고충실도 원본, 오른쪽에 051 디자인, 약 50/50 |
| `design-only` | 사용자가 확인한 전체 캔버스 | 051 디자인이 전체를 채우며 원본 사진은 보이지 않음 |
| `wallpaper-pack` | 기기별 확인 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

이중 패널 모드는 원본을 고충실도 편집／참조 입력으로 사용하고 완전한 스타일 프롬프트 한 세트로 최종 화면을 직접 생성합니다. 사진, 디자인, 색, 빛, 타이포그래피와 의미가 하나로 이어지게 하기 위해서입니다. 결정적 합성은 전체 캔버스 재시도 후에도 실패한 경우, 원본의 픽셀 완전 보존을 명시한 경우, 현재 경로가 목표 화면비를 만들 수 없는 경우, 또는 무손실 최종 픽셀 조정이 필요한 경우에만 사용합니다.

배경화면은 연결형 또는 독립형입니다. 연결형은 iPad 기준 작품 하나를 승인한 뒤 다른 기기를 원본＋같은 기준 작품에서 각각 재구성합니다. 독립형은 각 기기가 원본만 참조합니다. 어느 쪽도 다른 기기 결과를 자르거나 파생 결과를 연쇄 참조하지 않습니다.

## 문구, 래스터, 신뢰

생성 전에 자동 문구, 정확한 사용자 문구, 무문자 중 하나와 대상 언어를 확인합니다. 원문은 역사적으로 영어 제목을 언급하지만 영어를 기본값으로 두지 않고 대상 독자의 언어를 따릅니다. 자동 문구는 장소, 주체 정체성, 주제, 감정, 깊은 의미 또는 숨은 관계에서 짧은 제목 하나를 만듭니다. 작고 정교하며 살짝 손글씨 같은 문자를 풍경대 아래나 받침선을 따라 배치해 상업 제목이 아니라 제작자 서명처럼 통합합니다.

일반 크기는 원본에 적응하고 페어 모드는 정확히 50/50이며 모든 결과는 PNG입니다. 매 호출마다 `~/Desktop/xxd/xxd-panel-051/` 아래 새 작업을 만듭니다. 이미지 생성 경로는 민감 정보를 노출하지 않으며 SVG, HTML, Canvas, 프로그램 드로잉은 대체물이 아닙니다.

## 이미지 모델 우선순위

GPT Image 2를 기본 최우선 모델로 사용합니다. 고충실도 원본 참조, 생성 전 완성 캔버스 확인, 이중 패널의 완성 화면 일괄 생성, 조건이 충족될 때만 사용하는 스크립트 합성이라는 기존 흐름은 그대로 유지합니다.

현재 도구 또는 설정된 경로에서 실제로 사용할 수 있고 원본 충실도, 완성 화면비, 대상 언어의 문자, 연결형 배경화면의 다중 참조 요구를 충족할 때는 Seedance 5.0 Pro, Nano Banana Pro(Gemini Image Pro), Nano Banana 2(Gemini Image Flash) 또는 다른 호환 비트맵 모델도 사용할 수 있습니다. 대체 모델은 생성 경로만 바꾸며 모드, 캔버스, 문구, 언어, 배경화면 관계와 완성 캔버스 우선 전략을 바꾸지 않습니다.

적합한 경로가 없으면 이미지 생성 도구를 활성화하거나 API Key를 제공하도록 사용자에게 요청합니다. 사용자가 제공한 인증 정보는 현재 작업에 사용할 수 있지만 답변이나 로그에 다시 표시·기록·노출하지 않습니다. 사용자가 명시적으로 요청하지 않는 한 장기 저장하거나 제공자, 계정, 결제 또는 전역 경로 설정을 변경하지 않습니다.
